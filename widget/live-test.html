This is a plain host page standing in for a real client website — used to verify the embedded widget end-to-end against the real backend, not a mocked one.

Before you load this page

  1. This file must be served from a local static server (python -m http.server 8080, Live Server, etc.) — never opened directly via file://. Browsers don't send an Origin header for file://, and the backend's domain check rejects requests with no Origin.
  2. The port you serve this on must exactly match the Domain field set on the project (e.g. serve on 8080 if the project's domain is localhost:8080).
  3. That same origin must be in Django's CORS_ALLOWED_ORIGINS, or the widget's requests get blocked by the browser before they even reach the domain check.
  4. Replace the placeholder <script> tag at the bottom of this file with the real snippet copied from Settings → Rotate Key (or the wizard's Step 4 success screen) — it needs a real, working API key.

  • Opening the widget triggers GET /api/widget/config/ in the Network tab — returns 200 with the project's theme.
  • Sending a message triggers POST /api/chat/ — returns 200 with an answer.
  • The widget's own fonts/colors don't leak into this page, and this page's styles (the gray filler blocks, body font) don't leak into the widget — confirms Shadow DOM isolation is working both directions.
